# ESHub

音楽イベントのエントリーシート提出・管理を効率化するiOSアプリケーションです。 これまでExcelで行っていたエントリーシートの提出・管理業務をアプリ化することで、運営の負担軽減を目的に開発しました。

## Tech Stack
* **Frontend:** Swift
* **Backend:** Firebase

## Key Features
* **エントリーシートの一元管理:** 従来のExcelベースの管理から脱却し、アプリ上でシームレスに完結させます。
* **タイムテーブル自動作成:** ワンタップでイベントのタイムテーブルを自動生成します。
* **Universal Links対応:** Webリンクからアプリ内の特定画面へのスムーズな遷移を実現しています。

## The Process
音楽イベントの運営において、Excelを用いたエントリーシートの管理は煩雑で時間がかかるという課題がありました。 この課題を解決するため、ネイティブのiOSアプリとして設計し直しました。

データの保存や管理にはFirebaseをバックエンドとして活用し、 運営側が最も手間と感じていた「タイムテーブルの作成」をワンタップで自動化する仕組みを組み込んでいます。 チームに新しく参加したメンバーでもすぐに仕様を理解できるよう、シンプルで直感的なコードと構造を意識しています。
